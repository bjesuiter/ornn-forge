# Assets

This directory preserves visual work for Ornn Forge before an asset is adopted
by the application.

- `concepts/` contains candidate logos, favicons, and other visual directions.
- File names use a descriptive, versioned suffix (`-001`, `-002`, …) so that
  shortlisted ideas remain available for comparison.
- Assets are not production-facing until they are explicitly copied or adapted
  into the application's public asset location.

## Current concepts

- `concepts/forge-hammer-sparks-001.png` — blacksmith's hammer striking metal,
  with glowing, star-shaped sparks; initial favicon/logo direction.
- `concepts/forge-hammer-sparks-002-mirrored.png` — exact horizontal mirror of
  the initial direction, with the hammer entering from the upper right.
- `concepts/forge-hammer-favicon-flat-003.png` — a flat, geometric hammer,
  anvil, and three-spark concept designed for favicon use.
- `concepts/forge-hammer-favicon-flat-003-32.png` — the same concept rendered
  at its intended 32 × 32 pixel favicon size.
- `concepts/forge-hammer-favicon-boxy-004.png` — flat favicon candidate with a
  dominant boxy hammer head and exactly two forge-yellow sparks.
- `concepts/forge-hammer-favicon-boxy-004-32.png` — the same candidate rendered
  at its intended 32 × 32 pixel favicon size.
- `concepts/forge-hammer-favicon-no-anvil-005.png` — boxy hammer with three
  forge-yellow sparks emerging from an implied strike point; no anvil shown.
- `concepts/forge-hammer-favicon-no-anvil-005-32.png` — the same candidate
  rendered at its intended 32 × 32 pixel favicon size.
