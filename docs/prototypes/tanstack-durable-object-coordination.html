    Decision rule

    Keep a per-job Durable Object only if it owns a job that TanStack and D1 cannot do safely.

    • One live runner connection needs a stable owner.
    • D1 leases cannot settle a measured event race safely.
    • A sub-minute job alarm cannot use the TanStack host.
    PROTOTYPE ONLY. This page models ownership and failure cases. It does not contain production TanStack Workflow or Durable Object code.
